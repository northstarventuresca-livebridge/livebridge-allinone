# LiveBridge Independent Site

This repository contains ONLY the independent static LiveBridge website. 

## Included
- Landing page
- Signup
- Account
- Admin
- Sunday broadcaster page
- Azure listener page
- ClientPitch
- Live Stats
- Privacy
- Terms
- Legacy route redirects

## Not included
- Production Worker backend source
- Durable Object source
- D1 schema/migrations
- Wrangler production config
- Webflow beta files
- Great Church production files

## Cloudflare Pages settings
Build command: none
Build output directory: public

This repo is intentionally isolated from the current Webflow beta system.
